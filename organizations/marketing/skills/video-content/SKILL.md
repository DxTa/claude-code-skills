# Video content

## Inputs and context

Gather audience, video job, approved promise, topic evidence, format and runtime, platform, production resources, visual assets and rights, accessibility needs, sponsor status, brand rules, and any retention or click-through data.

## Workflow

1. Define the viewer outcome and create several accurate title/thumbnail concepts before production. Ensure the package promises something the video can deliver.
2. Open with the result, demonstration, or substantive tension; remove greetings and setup that delay the promised value.
3. Structure the piece for its length: one focused idea for short form, or purposeful chapters and transition reasons for long form.
4. Add shot, on-screen text, caption, b-roll, audio, and edit notes while scripting. Use visuals to show information rather than decorate it.
5. Plan stand-alone derivatives before recording and confirm that each retains necessary context.
6. Review factual claims, rights, disclosures, accessibility, brand approvals, and platform policy before publishing.
7. Diagnose performance by separating packaging, opening, transition, topic, and distribution signals.

## Output / decision record

Return viewer promise, package options and choice, script or outline, shot/edit notes, caption and accessibility plan, asset rights, sponsor disclosure, derivative list, test hypothesis, metrics, owner, and publication approval.

## Uncertainty and failure handling

Treat predicted click-through and retention as hypotheses. Use timestamps and comparable baselines before naming a cause. If a promise cannot be supported, change the package or scope. If a rights, safety, disclosure, or accessibility check fails, hold publication and name the owner for resolution.

## Routing boundaries

Use this skill only for its stated capability and required context. For adjacent work, select a more specific skill from `skill-index.tsv`; do not infer coverage from this department folder or use this skill to authorize actions outside its scope.

## Never

- Never package an outcome the video cannot substantiate.
- Never use unlicensed footage, music, likenesses, or testimonials.
- Never hide sponsorship, manipulate viewers, or ignore platform and accessibility rules.
