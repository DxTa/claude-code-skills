# Visual content

## Inputs and context

Gather the single message, source copy or data, audience, platform and display size, content shape, brand system, assets and rights, accessibility requirements, localization needs, and whether imagery is generated or sourced.

## Workflow

1. Choose the visual form that best represents the information: sequence, relationship, comparison, claim, quantity, or another justified structure.
2. Create a storyboard or layout with hierarchy, reading order, labels, one message per unit, and a clear conclusion.
3. For generated imagery, write a brief covering subject, composition, light, palette, mood, style, text restrictions, and negative constraints. Use only approved tools and inputs.
4. Build for the actual context, especially small screens. Check contrast, type size, color meaning, localization, captions, and alt text or an equivalent text description.
5. Verify every data label, citation, logo, person, and asset license. Inspect generated text and details manually.
6. Record the approved version and the change needed if the message is unreadable or unsupported.

## Output / decision record

Return format choice and rationale, message, storyboard or design brief, content/data sources, generation prompt if applicable, rights and approvals, accessibility description, dimensions, QA checklist, version, and publication decision.

## Uncertainty and failure handling

Mark estimates, incomplete datasets, uncertain relationships, and generated artifacts that need human inspection. If a visual cannot carry its message without tiny text or unexplained decoration, simplify or split it. Replace unreliable generated text with reviewed typesetting.

## Routing boundaries

Use this skill only for its stated capability and required context. For adjacent work, select a more specific skill from `skill-index.tsv`; do not infer coverage from this department folder or use this skill to authorize actions outside its scope.

## Never

- Never invent figures, sources, labels, quotations, or visual evidence.
- Never use an unlicensed asset or a person’s likeness without permission.
- Never rely on color, tiny text, or decorative complexity as the only way to convey meaning.
