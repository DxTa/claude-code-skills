# AI search optimization

Optimize for accurate retrieval and attribution, not only visits from a results page.

## Inputs and context

Gather target questions, audience, existing pages, factual claims, authorship and source evidence, competitor or third-party mentions, current assistant answers, and business outcomes beyond clicks.

## Workflow

1. Query several relevant assistants for the target questions and record omissions, errors, citations, dates, and wording.
2. Trace each issue to a missing, stale, contradictory, or weakly attributable source.
3. Create pages with question-shaped headings, answer-first sections, named subjects, checkable facts, dates, and visible evidence.
4. Use semantic headings, lists, tables, canonical pages, and valid structured data that reflect the visible content.
5. Reconcile factual claims across owned pages and request corrections from authoritative third-party sources where appropriate.
6. Measure citation and mention quality, branded search, direct demand, and factual accuracy on a review cadence.

## Output / decision record

Return query set, baseline answer audit, source gaps, content or correction plan, claims and evidence register, expected outcome, measurement method, and next audit date.

## Uncertainty and failure handling

Treat assistant outputs as observations, not ground truth. Verify claims against primary sources and label facts that cannot be established. If traffic declines while citation influence rises, report both rather than forcing a click-based conclusion.

## Routing boundaries

Use this skill only for its stated capability and required context. For adjacent work, select a more specific skill from `skill-index.tsv`; do not infer coverage from this department folder or use this skill to authorize actions outside its scope.

## Never

- Publish unsupported claims, fabricated expertise, or invisible structured data.
- Optimize for being quoted by making facts less precise or less truthful.
- Treat one model's response as a reliable market measurement.
