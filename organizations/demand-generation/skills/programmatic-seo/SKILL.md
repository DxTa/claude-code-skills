# Programmatic SEO

Scale only a page pattern that is genuinely useful at each instance.

## Inputs and context

Gather query research by instance, dataset coverage and freshness, search intent, ranking alternatives, single-page prototype, unique value, quality threshold, canonical and linking plan, publishing capacity, and removal criteria.

## Workflow

1. Verify real demand across many instances and confirm the dataset covers enough cases accurately.
2. Hand-build and review one excellent page to identify substantive variables and minimum evidence.
3. Define template fields, per-page quality gates, canonical rules, structured content, hub and cross-links, and analytics.
4. Generate a small batch and inspect content, indexability, duplicate risk, user value, and search behavior.
5. Compare against the existing results, then expand only when the batch clears quality and outcome thresholds.
6. Refresh, consolidate, or remove pages whose data or performance falls below the documented bar.

## Output / decision record

Return viability verdict, query and data evidence, prototype assessment, template and quality contract, rollout batch, linking and indexation plan, metrics, expansion gate, and retirement plan.

## Uncertainty and failure handling

If query volume, source coverage, or per-page value is uncertain, run a bounded sample rather than mass publishing. Quarantine missing-data instances and inspect indexation before attributing weak performance to ranking. Preserve a reversible generation and removal path.

## Routing boundaries

Use this skill only for its stated capability and required context. For adjacent work, select a more specific skill from `skill-index.tsv`; do not infer coverage from this department folder or use this skill to authorize actions outside its scope.

## Never

- Generate pages for empty or unreliable instances.
- Swap nouns in boilerplate and call the result unique.
- Launch a large page set without a quality gate and removal plan.
