# Listing distribution

Choose distribution points for buyer behavior and fit, not a large submission count.

## Inputs and context

Collect target buyers, evaluation journey, category destinations, directory quality, profile ownership, current descriptions and pricing, required assets, review policy, competitor alternatives, and maintenance capacity.

## Workflow

1. Rank destinations by evidence that target buyers consult them, editorial quality, qualified reach, effort, and risk.
2. Build a reusable, truthful asset kit with short and long descriptions, product details, screenshots, logo variants, pricing context, and contact owner.
3. Tailor required fields to each destination while preserving consistent claims, naming, and current links.
4. Claim and complete high-value profiles; request unbiased reviews at appropriate success moments and answer criticism specifically.
5. Create honest comparison or alternative pages that state where another option is stronger and keep claims current.
6. Schedule a periodic accuracy sweep and measure qualified traffic, evaluation actions, leads, and stale-listing corrections.

## Output / decision record

Return ranked destinations, inclusion and exclusion rationale, asset checklist, listing copy, owner and submission dates, review response policy, comparison-page evidence, maintenance cadence, and outcome metrics.

## Uncertainty and failure handling

Treat directory traffic and domain metrics as hypotheses until qualified buyer activity appears. Stop low-quality or risky bulk submissions. Mark unknown pricing, features, or competitor claims for verification instead of copying them.

## Routing boundaries

Use this skill only for its stated capability and required context. For adjacent work, select a more specific skill from `skill-index.tsv`; do not infer coverage from this department folder or use this skill to authorize actions outside its scope.

## Never

- Submit to a directory solely because it has a high authority score.
- Publish fabricated reviews, outdated prices, or one-sided comparisons.
- Start a listing push without an owner for updates.
